# Panel pack: governance

**Status:** used on a work policy tracker (Oct 2026), with the core reviewers. Six reviewers in all.

| Agent | Code | Holds precedence on |
|---|---|---|
| `governance-compliance-reviewer` | GC | Compliance harm: a record shown as more current than it is |
| `secretariat-reviewer` | CS | Meetings, deadlines, how outcomes are recorded |

Pair with `logic-auditor`, `adherence-reviewer`, `privacy-reviewer` (work data, roles not names) and
`data-reviewer`; add `automation-reviewer` if a routine runs.

**Invariants to start from:**
- The official record (the register, the minutes) always wins over the tool.
- A missing date is never "current". Missing information is never good news.
- An outcome is recorded only on the owner's word, never inferred.
- People are named by role, never by name. Nothing real is committed.
- Nothing goes live, and no routine writes, without the owner's yes.

**Ask the owner first:** who else can see it; which record is official; the bodies and their cycles; who must
approve the tool itself.

**Other stakeholders** (committee members, staff) are not on the panel. Name who speaks for them (the adherence
reviewer) and how their feedback is logged.
